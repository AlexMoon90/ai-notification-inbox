# MG 푸시 입출금 표시 수정 — 2026-10-04

실제 기기에서 알림 접근 권한, 앱 프로세스, 지속 수집을 확인했다. MG새마을금고(com.smg.spbs)의 입출금 알림 2건과 묶음 요약 1건이 저장돼 있었다. Now의 두 실알림 판정은 match이며 전달 대기열은 비어 있었다. 스마트함 처리만 retry였다.

원인은 `[입금]`, `[출금]`의 닫는 대괄호를 기존 금융 라벨 추출기가 허용하지 않은 것이다. 대괄호 라벨을 지원하며, MG의 `금액 계좌 잔액 금액 MM/dd HH:mm 상대방` 형식에서 원문 상대방을 추출한다. 원래 금융 추출의 광고/예정/실패 차단 및 거래금액·잔액 분리 조건을 유지한다. 원문에 있는 은행명을 별도로 표시한다.

기존 기록 보완은 로컬 규칙만 사용한다. 일반 AI 대량 재분류나 Now 정책 변경을 하지 않는다. 그룹 요약은 개별 금융 거래로 만들지 않는다. MG 외 다른 모든 알림이 정상이라는 일반화나 새 실알림의 소리/팝업 실험 완료를 뜻하지 않는다.

Now는 현재 비메신저 앱별 최신 표시 알림 한 건을 보여주는 구조다. 따라서 금융의 전체 입출금 기록은 스마트함에서 확인한다.

검증 완료: 단위 테스트 200개(실패/오류 0), Galaxy 계측 테스트 2개 통과. 기존 MG 2건 모두 거래금액·잔액·상대방 저장, 최신 MG 1건 Now 목록 포함을 실제 데이터로 확인했다. 업데이트 APK 설치 완료. 실제 신규 MG 알림의 소리/팝업은 별도 수신 테스트가 필요하다. 검증 자료에는 집계와 테스트 결과만 저장하고 원문·금액·상대방은 포함하지 않았다.
