# 알림 첨부 이미지 — 2026-09-27

사용자 요청: 카카오톡 등 알림 메시지에 실제 이미지 정보가 있으면 함께 표시한다.

## 구현

- MessagingStyle Message의 image MIME/dataUri를 수집 시 읽어 앱 내부 미리보기로 저장한다. content URI만 허용하고 HTTP 링크를 임의 다운로드하지 않는다. 원본 이미지나 URI를 AI에 보내지 않는다.
- MessagingStyle이 없는 알림의 EXTRA_PICTURE/EXTRA_PICTURE_ICON도 지원한다. 앱/사람 프로필용 large icon은 첨부 이미지로 사용하지 않는다. 이 이미지 때문에 일반 알림이 메신저 대화로 분류되지 않게 구분한다.
- 최대 10MiB 입력, 긴 변 1,024px 미리보기. 내부 PNG는 내용 해시 파일명으로 중복 저장을 줄인다. GIF 등은 첫 정지 프레임이며 동영상/애니메이션 재생과 OCR/이미지 의미 판단은 이번 범위가 아니다.
- 메시지 JSON에는 상대 파일명과 첨부 식별자만 보관한다. 원본 URI는 읽은 뒤 제거한다. 별도 서버/갤러리 저장 없이 앱 private files 사용. 기존 DB 스키마는 변경하지 않는다.
- 각 메시지에 이미지를 연결한다. 최신 답장이 텍스트이면 과거 이미지를 최신 답장의 이미지로 표시하지 않는다. 반복 MessagingStyle 이력에서 접근권한이 사라져도 이전에 보존한 같은 메시지의 미리보기 참조를 유지한다.
- Now/분류함 행은 작은 미리보기, 대화 메시지/상세는 큰 미리보기. 이미지를 누르면 확대 창을 연다. 읽을 수 없는 첨부는 ‘사진 · 원래 앱에서 확인’으로 남긴다.
- 전체 저장 기록 삭제 시 내부 이미지도 함께 삭제한다. 기존 이미지 없이 텍스트만 저장했던 과거 알림은 원본을 복원하지 않는다. 여전히 활성화된 원본 알림은 Listener 재연결 시 다시 관측할 수 있다.

Android 근거: [MessagingStyle.Message](https://developer.android.com/reference/android/app/Notification.MessagingStyle.Message), [Notification](https://developer.android.com/reference/android/app/Notification). 원본 앱이 URI 접근을 허용하지 않거나 이미지 자체를 제공하지 않으면 표시를 보장하지 않는다.

## 검증

단위 검사: 저장/크기 제한/내부 파일 경로/삭제, 프로필 아이콘 제외, 일반 이미지 알림의 메신저 오분류 방지, 사진 뒤 텍스트 답장, URI 권한 없음의 안전한 fallback.

Galaxy 검사: 테스트용 Bitmap 미리보기/확대 UI와 카카오톡 실제 활성 알림의 이미지 메타데이터·읽기 가능 여부를 별도 검사한다. 실제 사용자 이미지·본문은 검증 자료로 내보내지 않는다. 완료 결과는 아래에 추가한다.


## 이미지 표시 구현·설치 — 2026-09-27

[이미지 처리 범위](NOTIFICATION_IMAGES.md)를 구현했다. 단위 100개, 빌드/lint 통과. Galaxy에 설치하고 테스트용 Bitmap의 미리보기·확대 UI 및 활성 Kakao 메타데이터 검사 2개 통과(5.329초). 실제 Kakao 활성 알림은 0개여서 카카오톡 이미지 URI 읽기 성공은 아직 검증하지 못했다. 사진 알림 수신을 사용자에게 요청했다. 이 메타데이터 검사 통과를 실제 사진 표시 성공으로 간주하지 않는다.

기존 기록 9,071개 전체 필드 해시·정책 해시 보존 확인. DB는 v3 유지, 설치 후 기록 9,072개. 이미지의 AI 전송은 추가하지 않았다. 사진 미제공/권한 만료는 원래 앱 확인으로 남긴다. 사용자 이미지는 호스트 검증 자료에 내보내지 않았다. 테스트 후 앱 재실행. 자료: evaluations/notification-images/. 전체 Phase 상태 유지.


## 대화방·발신자 썸네일 확장 — 2026-09-27

사용자 요청으로 대화방 목록/상세의 썸네일과 메시지 발신자 프로필을 추가한다. 알림의 largeIcon은 대화 알림 썸네일 후보, MessagingStyle Person.icon은 해당 메시지 발신자 프로필로 구분해 내부 파일에 저장한다. 큰 알림 아이콘이 단톡 발신자 사진과 같으면 방 이미지로 쓰지 않는다. 1:1로 명시된 대화에서는 방 이미지가 없을 때 관측한 발신자 사진을 사용할 수 있다. 다른 발신자의 사진을 이름만으로 복사하지 않는다. 알림이 사진을 제공하지 않으면 이름 첫 글자 표시다.

[Android Person API](https://developer.android.com/reference/androidx/core/app/Person)를 사용한다. 프로필은 첨부 사진/AI 입력과 분리하며 외부 웹 조회나 연락처 권한을 추가하지 않는다. Room v3→v4에 nullable conversationAvatarFile만 추가하고, senderAvatarFile은 메시지 JSON에 저장한다. 방을 합치는 기준은 변경하지 않는다. 썸네일은 128px, 기존 private 이미지 저장소를 사용하며 기록 전체 삭제 시 함께 삭제한다. 원래 앱의 알림 이미지가 실제 방 대표 사진인지 여부는 앱의 제공 방식에 의존하며, 참여자 사진과의 명확한 중복만 코드로 제외할 수 있다.


## 대화방·발신자 썸네일 설치 검증 — 2026-09-27

알림의 대화 썸네일과 각 발신자 프로필을 별도 저장·표시했다. 단위 102개, 빌드/lint 통과. Galaxy 설치 후 테스트용 방/발신자 프로필 UI, 기존 첨부 이미지 확대, Kakao 활성 알림 메타데이터 검사 3개 통과(6.787초). 합성 화면에서 방 썸네일과 발신자 프로필을 확인했다. 실제 Kakao 활성 알림이 0개여서 실제 프로필/첨부 URI 제공 여부는 미확인이다.

DB v3→v4 이전 후 기존 기록 9,072개 전체 기존 필드 해시 일치, 정책 해시 일치. 사용자 사진은 외부 AI나 검증 폴더에 내보내지 않았다. 새 알림에 프로필이 제공되면 표시하고, 과거 미수집 프로필이나 제공되지 않은 사진은 이름 첫 글자로 표시한다. 실제 앱 재실행 완료. 자료: evaluations/conversation-avatars/. 전체 Phase 게이트 유지.


### Now 썸네일 — 2026-09-27
Now 및 공통 알림 행에 메신저 대화방 썸네일과 최신 메시지 발신자 프로필을 표시한다. 기존 출처 앱 아이콘은 유지한다. 사진이 없으면 이름 첫 글자를 표시한다. 저장된 프로필만 사용하며 다른 발신자의 사진을 빌려 쓰지 않는다. 빌드 통과. Now→메신저→대화방 프로필 UI 검사를 준비했으나 Galaxy 연결이 끊겨 설치·실기기 검증은 대기 중이다.

단톡방 제목 표시: Now/알림 상세/메신저 방 목록은 알림의 conversationTitle을 우선 사용한다. isGroupConversation=true이고 방 제목이 null/공백이면 ‘단톡방’으로 표시하며, title에 들어 있는 발신자 이름으로 대체하지 않는다. 화면 이름만 바꾸고 실제 대화 식별자는 유지하므로 이름 없는 서로 다른 방을 합치지 않는다. 단톡방 여부가 제공되지 않은 알림은 임의로 단톡방으로 단정하지 않는다.


### 발신자 중심 썸네일·대화 사진 — 2026-09-27
사용자 요청에 따라 Now/대화방 목록의 대표 썸네일을 최신 메시지의 발신자 프로필로 변경한다(단톡방 포함). 프로필 미제공 시 발신자 이름 첫 글자를 사용하며 방 사진을 발신자 사진으로 오인해 표시하지 않는다. 방 내부의 각 메시지는 해당 발신자 프로필을 유지한다. 최신 메시지가 이미지 MIME이고 URI 미리보기를 읽지 못했을 때 EXTRA_PICTURE/PICTURE_ICON이 제공되면 그 이미지 메시지에 연결한다. 이전 사진 뒤의 텍스트 답변에는 이미지를 붙이지 않는다. 대화 안에서 사진 미리보기 및 확대를 제공한다. 사진 데이터가 제공되지 않거나 읽기 권한이 없으면 원래 앱 확인 안내를 유지한다.


### 단톡방 대표 사진 기준 변경 — 2026-09-27
최신 사용자 요청은 앞선 ‘단톡방 목록도 발신자 프로필’ 지시를 대체한다. Now와 메신저 방 목록에서 단톡방은 저장된 방 썸네일을 사용하고 발신자는 이름만 표시한다. 방 내부 메시지는 발신자 프로필을 유지한다. 1:1 대화는 발신자 프로필을 사용한다. 단톡방 사진 미제공 시 방 이름 첫 글자를 표시하며 발신자 사진으로 방 사진을 대체하지 않는다.
