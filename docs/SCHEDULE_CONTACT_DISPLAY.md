# 일정 상대방 표시 — 2026-10-06

일정 대시보드 카드, 목록(간략 미리보기 포함), 상세 제목 아래에 상대방을 표시한다.

- 기존 일정의 참여자를 우선 사용하고, 없으면 수신 원본의 대화 이름/제목으로 보완한다. 저장된 연락처 이름 또는 문자 전화번호를 표시한다.
- 위 정보가 없는 경우 원본에 명시적으로 들어 있는 tel: 번호로 보완한다.
- 단톡방은 대화방 이름을 표시한다. 방 이름 없이 보낸 사람만 관측된 경우 보낸 사람으로 구분한다.
- 연락처 조회나 이름 추측을 하지 않는다. 이용 가능한 정보가 전혀 없으면 정보 없음으로 표시한다.
- 일정에 연결된 원본의 이름 관련 열만 조회한다. 본문 전체 로딩, AI 재분석, DB 스키마 변경 없이 기존 일정에도 적용된다.
- 직전 AI 호출 한도 제거 수정도 이번 APK에 포함한다.

검증 및 설치 상태:

- `assembleDebug` 성공. 사용자 지시에 따라 추가 테스트는 실행하지 않았다.
- ADB 연결 기기가 없어 이번 APK 설치와 실기기 화면 확인은 수행하지 못했다.
- 설치용 APK: `/private/tmp/money-native-output/app/outputs/apk/debug/app-debug.apk`.
