# 기준 편집 전용 창과 앱 옆 정렬 — 2026-09-24

## 사용자 흐름

새 요청의 음성/텍스트 확인 이후, 처리 중 표시 → 보충 질문·답변 → 변경 비교 → 최종 적용을 별도 ‘기준 확인’ 창에서 진행한다. 질문 답변을 제출하거나 검증 결과가 바뀌어도 창은 유지된다. 적용 성공으로 제안이 없어졌을 때 연결도로 돌아온다. 검증/저장 실패 시 오류를 같은 창에 남겨 확인·재시도할 수 있다.

연결도에는 적용된 기준만 표시한다. 검토 중인 부분 규칙을 연결도에 섞거나 변경 카드를 본 화면 하단에 나열하지 않는다. 닫기/뒤로/나중에 계속은 제안을 삭제하지 않으며 본 화면의 ‘작성 중인 변경 이어서 확인’으로 재개한다. 명시적인 수정안 취소만 기존 discard 경로를 호출한다. 직접 변경/삭제/범위 변경의 검토도 같은 창으로 연결하며, 기존 검증·사용자 확인·저장 계약을 유지한다. 온보딩의 전용 질문 흐름은 변경하지 않는다.

## 관계도 배치

앱 아이콘을 24dp로 축소하고 이름은 작은 보조 글자로 표시한다. 앱 최소 구간은 56dp에서 40dp로 줄인다. 각 앱 구간의 높이는 연결된 개별 조건 수에 따라 확장한다. 개별 조건은 목록의 위에서부터 독립 나열하지 않고 해당 앱 구간 옆에 수직 중앙 정렬한다. 한 앱에 여러 조건이 있으면 그 앱 옆에 모인다. 여러 앱에 제한된 개별 조건은 각 해당 앱 옆에 같은 원본 기준의 연결로 표시한다. 공통 기준은 왼쪽 한 번 표시를 유지한다. 텍스트 한 줄 Clip과 좌우 드래그, 첫 터치 연결 강조/추가 터치 설정 흐름을 유지한다.

## 검증

최종 실행 결과는 `evaluations/policy-review-dialog/result.json`에 기록한다. 기기 검사는 격리된 합성 기준과 고정된 AI 응답으로 질문→답변→Diff→닫기→재개→확인/저장을 검사하고 원래 사용자 정책이 유지되는지 확인한다. 두 앱의 각 개별 텍스트 중심과 해당 앱의 중심 위치도 확인한다. 이번 UI 변경은 새로운 AI 의미 정확도 검사나 Phase 전체 완료를 뜻하지 않는다.

단위/렌더링 64개, debug/test APK 빌드·lint를 통과했다. 추가 네이티브 렌더에서 카카오톡/WhatsApp의 각 개별 조건이 해당 앱 옆에 정렬되는 것을 확인했다. 기기가 ADB 연결 목록에서 사라져 이번 버전의 설치와 실기기 Dialog 흐름 검사는 아직 수행하지 못했다. 연결 후 위 테스트 2개 실행과 모달 화면 확인이 남아 있다.


USB 재연결 후 Galaxy에 APK를 설치했다. 기존 연결도/드래그/초기화 회귀가 통과했고, 질문→답변→변경 확인→닫기→재개→최종 적용과 두 앱의 인접 정렬이 27.677초에 통과했다. 최초 새 테스트의 동일 조건 두 개가 공통으로 묶여 개별 노드를 찾지 못했으므로 서로 다른 기준으로 테스트 데이터를 수정했다. 실제 사용자 기준 보존 assertion도 통과했고 외부 API 호출은 없었다. Galaxy 화면에서 별도 모달과 인접 정렬을 확인했다.


## 사용자 결과 중심 확인 화면 — 2026-09-25

자연어 요청 후 내부 정리 메시지·검증 사유·미완성 JSON 설명·변경 없는 기준 목록을 화면에서 제거했다. 보충 질문은 질문과 선택지, 직접 답변/대화 선택 진입으로 구성한다. 확정 결과는 추가/변경/삭제와 대상·조건 → 처리만 보여주며 실제 예외·시간·꺼짐 상태는 의미가 달라지지 않도록 남긴다. 변경 시 이전 결과도 간단히 표시한다. 상세 원본 정책 화면 및 검증/확인 후 적용 절차는 유지한다.
