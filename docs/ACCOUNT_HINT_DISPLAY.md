# 금융 알림 계좌 구분 표시 — 2026-10-04

사용자가 같은 새마을금고의 문자와 앱 푸시를 서로 다른 두 계좌로 이용한다고 확인했다. 전송 앱이나 은행명만으로 같은 계좌로 취급하지 않는다.

- 원문 은행 문자 `<은행>계좌 … 입출금액`과 MG 푸시 `[입금/출금] 금액 계좌 잔액 …`의 계좌 위치에서 식별 문자열을 추출한다. 명시적인 `계좌번호:` 라벨도 지원한다.
- 원문에 이미 가려진 계좌번호는 그대로 보존한다. 전체 번호인 경우 표시/저장 힌트에는 끝 네 자리만 남기고 앞 숫자를 가린다. 원문에 없는 숫자를 생성하지 않는다.
- 스마트함 목록과 상세에 은행명 + 계좌 힌트를 표시한다. 기존 MoneyEvent.accountHint 필드를 사용하므로 DB 스키마 변경은 없다.
- 계좌 후보가 여러 개면 임의로 고르지 않는다. 이 표시용 힌트는 완전한 계좌 ID가 아니다. 서로 다른 마스킹 형태를 자동으로 동일 계좌로 연결하거나, 은행명만 같은 거래를 합치지 않는다.
- 기존 금융 기록은 로컬 규칙으로 다시 추출한다. 원본은 보존하고 외부 AI 대량 분석을 실행하지 않는다.
- 체크카드 결제·계좌 출금의 거래 통합은 별도 미완료 작업이며 이번 변경에 포함하지 않는다.

실제 기록 로컬 반영에서 계좌 표시 39건과 새마을금고의 서로 다른 계좌 힌트 2개를 확인했다. 최초 화면 검증은 출처·시간과 결합된 텍스트에 독립된 계좌 문구를 기대해 실패했다. 화면에서도 계좌가 잘리지 않도록 은행·계좌 줄을 출처·시간 줄과 분리했다.

최종 검증: 단위 테스트 201개 통과. Galaxy 로컬 기록 보완 성공, 수정 후 계좌 줄·거래금액·잔액 분리·원본 접근 화면 테스트 1개 통과. 최종 APK 설치. 로컬 원문 검토 27,014건 중 명확한 금융 알림 64건 반영, 계좌 표시 39건, MG 계좌 힌트 2개. 외부 호출 0회. 공개 검증 자료는 집계와 합성 테스트 로그만 포함한다.
