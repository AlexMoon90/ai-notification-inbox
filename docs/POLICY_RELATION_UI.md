# 알림 기준 관계도 — 2026-09-24

사용자가 선택한 이미지의 앱 내부 화면을 기존 Kotlin/Compose 설정 화면에 적용했다. 이미지 바깥의 설명 패널과 iPhone 프레임은 앱에 넣지 않는다. Phase 0 전체 수집 게이트와 AI Watch 구현 상태는 변경하지 않는다.

## 구현

- 공통 상황 / 앱 / 개별 지시사항의 세 열. 실제 정책의 조건 유형과 앱 범위에서 관계를 만든다.
- 상황 또는 앱 선택 시 관련 연결·기준을 강조하고 나머지는 흐리게 표시한다. 전체 연결 보기로 해제한다. 선택 자체는 정책을 변경하지 않는다.
- 가운데 손잡이를 끌어 좌우 열 너비 조절. 많은 조건은 관계도 안에서 세로 스크롤한다.
- 실제 설치 앱 아이콘을 사용하며 전체 앱 범위는 ‘모든 앱’ 한 노드로 표시한다. 시안의 브랜드나 예시 규칙을 실제 사용자 데이터에 추가하지 않는다.
- 개별 기준 탭 → 상세 창 → 적용 체크, 처리 방식, 범위, AI 수정, 삭제. 의미 있는 변경은 기존 검증·Diff 확인 경로를 유지한다.
- 새 기준과 추가 설정(방해 금지 시간, 기준별 예외)은 입력 창과 기존 정책 편집 흐름으로 연결된다. 방해 금지는 Inbox 규칙이며 OS 방해 금지를 켜는 기능이 아니다.
- 적용 기준과 검토 중 기준을 구분한다. 부분 미리보기는 읽기 전용이고 원래 기준을 대체하지 않는다.

## 초기화

화면에서 삭제 범위를 확인해야 실행한다. 활성/꺼짐 정책, 레거시 rulebook, 현재 수정안, 정책 입력과 온보딩 입력을 제거한다. 기존 알림·분류 이력, 사용량 한도, API 설정, 정책 버전 보관은 유지한다. 별도의 이전 방식 초안 보관함은 삭제하지 않는다. 앱 최초 온보딩으로 강제로 이동하지 않는다.

저장 직전 정책 revision이 확인 창을 연 시점과 일치해야 한다. 정책 편집 작업 중에는 초기화를 막는다. 진행 중인 분류는 확인 필요로 전환하고 옛 정책의 늦은 결과는 현재 정책 ID 검사를 통과하지 못한다. 초기화 이후 새 알림은 사용자 조건으로 숨기지 않는다.

## 검증 범위

최종 빌드/테스트 결과는 `evaluations/policy-relation-ui/result.json`에 기록한다. 자동 테스트에는 범위·다중 조건 관계도 투영, 초기화 revision 검사·저장 복원·이력 및 한도 보존을 포함한다. Native Robolectric 렌더링은 실제 Compose 컴포넌트를 합성 정책으로 그린다. 실기기의 앱 아이콘·터치·OEM 동작 검증을 대체하지 않는다.

Galaxy 자동 테스트 `relationNavigationAndConfirmedReset`은 격리된 DB/합성 정책에서 선택, 상세, 초기화 취소/확인, 재읽기를 검사하도록 추가했다. 화면 캡처 허용은 테스트가 합성 화면을 띄운 뒤에만 적용한다. 제품의 FLAG_SECURE는 유지한다. 이번 작업 중 실제 사용자 정책을 초기화하지 않는다.

## 텍스트 중심 관계도 — 2026-09-24 후속 요청

사용자 후속 요청이 원본 이미지의 말풍선/카드 표현보다 우선한다. 관계도의 헤더·조건·앱 선택 배경과 테두리를 제거한다. 조건 이름은 한 줄로만 표시하고 영역 바깥은 Clip 처리하며 자동 줄바꿈·말줄임표를 넣지 않는다. 전체 문구와 처리 방식은 상세에서 확인한다. ‘언제/어디서/어떻게’는 삭제한다.

관계도 위에서 직접 좌우 드래그하면 두 열의 너비가 반대로 바뀌고 앱 열과 연결선도 함께 이동한다. 오른쪽 드래그는 왼쪽 확대, 왼쪽 드래그는 오른쪽 확대다. spring 보간으로 이동을 부드럽게 연결하며 드래그를 놓으면 현재 너비를 유지한다. 하단 슬라이더도 같은 방향이다. 이 조작은 화면 상태만 바꾸며 정책을 수정하지 않는다.

## 촘촘한 기본 목록과 터치 후 연결 보기 — 2026-09-24

조건 행의 최소 높이를 48dp→30dp, 행 간격을 10dp→0dp로 줄였다. 첫 항목 자동 선택을 제거했다. 첫 텍스트 터치에서는 기본 화면의 스크롤·너비를 유지한 채 배경을 어둡게 하고, 선택 텍스트와 연결된 앱 아이콘/선을 별도 레이어로 보여준다. 배경 또는 닫기/뒤로를 누르면 원래 화면으로 돌아온다. 선택 텍스트를 다시 누르면 설정하기를 보여주며 이때까지 정책 저장이나 수정은 하지 않는다.

공통 상황에 여러 규칙이 연결된 경우 설정할 규칙을 고른다. 검토 중 정책은 기존 읽기 전용 상세를 유지한다. 전체 앱 범위는 수신 기록의 실제 앱 아이콘을 표시하고, 관찰한 앱만 표시한다는 안내를 붙인다. 앱 기록이 없으면 모든 앱 노드로 표시한다. 실제 기준의 범위를 변경하지 않는다.


## 앱별 전체 연결 보기 — 2026-09-24

기본 관계도 또는 텍스트 강조 레이어의 앱 아이콘을 누르면 전체 정책에서 해당 앱의 관계를 다시 계산한다. 공통 상황 → 선택 앱 → 개별 지시사항을 같은 전경에 표시하며, 전체 앱 기준과 꺼진 기준도 포함한다. 다른 앱에만 적용하는 기준은 제외한다. 대화·발신자·시간·예외의 상세 제한은 기존 정책 그대로 유지하고 안내한다. 공통 상황 또는 개별 기준을 누르면 설정하기로 이어진다. 선택 자체는 정책을 수정하지 않는다.

단위/렌더링 61개, debug/test APK 빌드·lint 통과. Galaxy의 합성 기준으로 공통/개별 연결, 앱 아이콘 진입, 설정 상세, 초기화 및 실제 정책 보존을 통과했다(63.804초, API 0회). 앱별 포함/제외 조합은 단위 테스트, 실제 아이콘/양쪽 연결은 기기 테스트로 확인했다. 결과: `evaluations/policy-relation-ui/app-connections/result.json`.


## 공통 처리 기준과 개별 조건 구분 — 2026-09-24

[공통 그룹화 계약](POLICY_COMMON_GROUPING.md)에 따라 왼쪽은 실제 공통 기준, 오른쪽은 개별 조건으로 변경했다. 같은 내용이 양쪽에 반복 나열되지 않는다. 앱 선택에서도 동일한 구분을 유지한다. 같은 별도 저장 규칙은 원본을 유지해 묶고 설정 시 원래 대상별 기준을 선택한다.


## 연결선 가독성·아이콘 밀착 — 2026-09-24

앱 열을 40dp로 고정하고 양옆 간격을 6dp로 줄였다. 연결점은 앱 이름까지 포함한 행 대신 실제 24dp 아이콘 경계에서 1dp 떨어진 곳에 붙인다. 기본 연결선은 불투명 파란색(#587CB5) 2dp, 강조 화면은 밝은 파란색(#B4D0FF) 2dp이며 둥근 끝과 연결점을 표시한다. 단일 텍스트 강조 화면도 앱 열 40dp·간격 8dp로 줄였다. 드래그·선택·설정 동작과 정책 내용은 유지한다.

대상 네이티브 렌더 1개·debug/test 빌드·lint 통과. Galaxy 설치 후 연결도/드래그/선택/상세/초기화 격리 회귀 1개 통과(56.957초, API 0회). 기본·앱 선택·텍스트 선택 화면을 직접 확인했다. 사용자 정책은 보존했다. [검증 결과](../evaluations/policy-relation-lines/result.json).


## 왼쪽 문구 오른쪽 정렬·텍스트 연결점 간격 — 2026-09-24

왼쪽 공통 문구는 오른쪽 정렬하고 연결점 쪽에 6dp 안쪽 여백을 확보했다. 오른쪽 개별 문구도 연결점 쪽 6dp 여백으로 점과 글자의 겹침을 방지한다. 기본·앱 선택·텍스트 선택 화면 모두 적용했다. 아이콘 쪽 밀착은 유지한다. 대상 네이티브 렌더 1개·debug/test 빌드·lint, Galaxy 격리 관계도 회귀 1개 통과(56.851초). 세 기기 화면을 직접 확인했다. API 0회, 사용자 정책 보존, Phase 전체 상태 유지. 검증 자료: `evaluations/policy-relation-text-spacing/`.


## 출처 아이콘·대상별 규칙 입력 — 2026-09-24

알림 목록·상세에 18dp 실제 앱 아이콘(조회 실패 시 일반 알림 아이콘)을 추가했다. 알림의 앱 이름과 관계도 앱 설정에서 앱 대상 입력, 알림 상세에서 관측된 대화 ID/500자 이내 예시를 포함한 입력, 기준 상세에서 기존 rule ID와 scope를 유지한 수정 입력을 제공한다. 빈 요청으로 시작하고 사용자 요청과 대상 참조를 기존 PolicyController 검증/질문/Diff 확인으로 전달한다. 기존 검토안이 있으면 먼저 이어서 표시한다. 입력만으로 저장하지 않는다.

단위 64개·빌드·lint 통과. Galaxy 설치 및 격리 UI 검사 통과(74.775초): 앱/기준 대상 입력 진입, 빈 입력 제출 비활성, 입력 후 활성, 취소 시 정책 보존, 기존 연결도 동작. API 0회. 새 경로의 실제 OpenAI 왕복과 Timeline 아이콘의 기기 시각 검증은 이번 검사에 포함하지 않았다. Phase 전체 상태 유지. 검증 자료: evaluations/context-policy-ui/.
