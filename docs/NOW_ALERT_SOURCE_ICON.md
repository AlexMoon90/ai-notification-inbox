# Now 재통지 원본 앱 로고 — 2026-10-06

사용자 요청에 따라 Now에서 선별해 발행하는 Android 알림에 원본 앱의 설치된 런처 아이콘을 large icon으로 추가한다. 제목은 원본 앱 이름과 대화/알림 제목을 표시하며 동일한 이름의 반복은 제거한다.

- 게시 앱 표기와 small icon은 NOWSET을 유지한다.
- PackageManager로 기기 안의 앱 아이콘을 조회한다. 외부 이미지 다운로드나 추가 권한은 없다.
- 아이콘은 48dp, 최대 192px로 제한하며 별도 누적 캐시를 만들지 않는다.
- 삭제된 앱 등으로 아이콘 조회가 실패해도 기존 텍스트 알림은 발행한다.
- 선별 조건, 채널, 소리, 방해금지, 클릭 이동 및 읽음 처리는 변경하지 않는다.
- 이미 발행된 알림을 재발행하지 않고 이후 새 알림에 적용한다.

표시 제한: 알림창/팝업에서 large icon의 위치와 노출은 Android 및 One UI 알림 스타일에 의존한다. 상태표시줄은 NOWSET small icon을 유지한다. 실제 새 수신 알림의 시각적 확인은 별도이며 구현만으로 확인 완료로 기록하지 않는다.

검증/설치: `assembleDebug` 성공. Galaxy S23에 `adb install -r` 성공으로 기존 데이터 유지 업데이트 완료. 추가 테스트 알림이나 실기기 화면 테스트는 수행하지 않았다. 다음 실제 수신 알림의 로고 노출은 사용자 확인이 남아 있다.
