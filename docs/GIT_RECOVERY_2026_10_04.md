# Git 복구 및 최신 수정본 백업 — 2026-10-04

복구 브랜치: codex/recovery-2026-10-04

## 복원 범위

- 마지막 Galaxy 설치에 사용한 임시 빌드 사본에서 Android 소스, 단위 테스트, 일부 계측 테스트, Room 스키마, Gradle 설정 125개 파일을 먼저 복원했다. 사본과 SHA-256 일치를 확인했다.
- 기존 원격 저장소의 Git 이력을 다시 연결하고, 누락된 추적 파일 414개를 원격 버전으로 복원했다. 복원해 둔 최신 소스는 덮어쓰지 않았다.
- 이전 원격 문서와 개발 스크립트는 9월 27일 상태일 수 있다. 최신 변경을 모두 설명한다고 간주하지 않는다. 사용자가 이전 AGENTS 지침 적용을 철회한 사실은 파일 복구로 바뀌지 않는다.
- 최근 변경에는 Now/메시지 보완, 스마트함 3안, 대화 문맥 처리, 금융 거래금액·상대방·기관 추출, 자체 앱 금융 중복 제외, 카카오페이 서비스 메시지가 포함된다.
- 체크카드 결제와 은행 출금의 거래 통합은 아직 구현되지 않았다.

## 검증과 제한

- 마지막 기능 변경 시 단위 테스트 199개와 Galaxy 계측 테스트 2개가 통과했다.
- 복구 후 Gradle kotlin-dsl/transforms 캐시 파일 누락을 발견해 별도 보관 후 재생성했다. 동일 소스의 기존 컴파일 및 테스트 캐시를 재사용한 debug 빌드가 성공했다. 전체 테스트를 새로 실행한 것으로 기록하지 않는다.
- 원격에서 복원한 오래된 계측 테스트까지 전부 재검증하지 않았다.
- 최신 debug 설정 생성 스크립트는 유실되어, 이 컴퓨터의 마지막 검증된 비공개 debug assets를 복사하는 복구용 스크립트를 사용한다. 새 컴퓨터에서는 해당 로컬 설정을 별도로 준비해야 한다.
- API 키, 실제 알림 DB/원문, 로컬 복구 압축본, APK는 새 커밋에서 제외한다. recovery/는 Git ignore 대상이다.

## 이후 저장 방식

사용자가 요청한 대로 검증된 작업 단위마다 커밋하고 원격 브랜치로 push한다. 커밋만으로 원격 백업됐다고 말하지 않고, 원격 ref가 로컬 커밋과 일치하는지 확인한다. 공개 저장소이므로 키·실제 사용자 데이터·개인 테스트 APK를 포함하지 않는다. 기존 기본 브랜치에는 이 복구 작업에서 강제 push하거나 자동 병합하지 않는다.
