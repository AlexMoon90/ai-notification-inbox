# 앱 자체 AI 횟수 한도 제거 — 2026-10-06

사용자가 앱 내부의 AI 횟수 한도를 없애도록 명시적으로 요청했다.

- MoneyPipeline의 Jev 일일 200회, OpenAI 구조 분석 일일 20회 차단을 제거했다.
- 명시적으로 시작한 과거 재분석의 Jev 12,000회, 구조 분석 500회 차단도 제거했다.
- 일자별/종류별 호출 수 및 재분석 진행 집계는 유지한다. 기존 저장값을 초기화하거나 새 키를 만들지 않는다.
- Now 선별은 이미 호출량만 기록하며 횟수로 차단하지 않는 상태임을 확인했다.
- 과거 재분석을 새로 시작하지 않는다. 정상 처리 대기열은 기존 재시도 시각에 따라 진행된다. 기존 실패 사유가 DB에 구분 저장되지 않았으므로 모든 실패 항목의 대기 시간을 일괄 초기화하지 않는다.
- API 오류 시 재시도 간격, 캐시/중복 방지, 메시지 입력 크기 제한은 횟수 한도가 아니며 유지한다. 외부 공급자의 응답 제한은 앱에서 해제할 수 없다.

검증: 이전 상한값에 도달한 상태에서 새 판단/구조 분석 집계가 203/23으로 진행되고, 재분석 집계가 12,001/501로 진행되는 회귀 테스트 추가. 테스트는 외부 API를 호출하지 않고 호출 직전 경로의 차단 제거와 집계를 검증한다. 재분석이 자동 활성화되지 않는 것도 확인한다.

진행 결과: 이미 시작했던 빌드/단위 테스트 작업은 정상 종료했다. 이후 사용자가 추가 테스트와 반복 확인을 생략하도록 요청해 더 실행하지 않았다. APK 빌드 완료. 마지막 ADB 조회에서 연결된 단말이 없어 설치는 미완료이며, 실기기 완료로 기록하지 않는다.
