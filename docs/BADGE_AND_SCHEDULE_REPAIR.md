# 읽음 배지와 일정 메시지 누락 수정 — 2026-10-06

앱 아이콘 숫자는 시스템 알림창의 Now 재통지에 의해 표시되었지만, 대화/스마트함의 읽음 상태와 연결되지 않았다. 알림의 자동 취소는 시스템 알림을 직접 눌렀을 때만 적용되어 앱 안에서 읽어도 남았다. 조사 시 앱 소유의 Now 알림 41건이 남아 있었다(자동 그룹 요약 제외).

최근 일정 문자들은 `structured_processing=retry`였고, 당일 판단 사용량은 200/200이었다. 기존 로컬 보완은 단톡방의 날짜 하나짜리 미팅 공지만 처리했다. 여러 후보 날짜를 제안한 문자, 예약 변경 요청, 취소 요청은 이 경로를 사용하지 못했다.

## 변경

- Now 및 앱별 기록의 실제 보이는 목록, 알림 상세, 열린 대화의 읽음, 스마트함 목록/상세 확인을 해당 Now 알림 취소에 연결한다. 읽지 않은 알림은 유지한다. 원본 앱 알림이나 저장 원문은 삭제하지 않는다.
- 읽음 표식을 먼저 저장하여 늦게 끝난 판단이 이미 읽은 항목을 다시 통지하지 않게 한다. 기존 대화/스마트함 읽음 기록을 앱 시작 때 복구하고, 48시간이 지난 Now 시스템 알림도 정리한다. 대화 읽음에서 배지용으로 전달하는 소스는 최근 48시간으로 제한한다.
- 명시적인 메시지의 일정 날짜/시각 후보, 변경·취소를 로컬에서 추출한다. AI 한도와 무관하게 동작하며 광고, 예시, 부정문, 이용시간·쿠폰 사용 기한·모델 버전 숫자, 대상이 없는 짧은 답장은 자동 일정으로 확정하지 않는다.
- `일정 조율`, `변경 요청`, `취소 요청`, `변경`, `취소`를 구분한다. 복수 날짜/시각은 원문에 있는 표현을 보존하며 오전/오후, 주차, 수락 여부를 만들어내지 않는다. 조율 중인 건은 확정 예정 건수에 넣지 않는다.
- 과거에 구조화 이벤트가 없는 소스만 페이지 단위로 복구한다. 이미 있는 이벤트/사용자 수정은 덮어쓰지 않는다. 과거 Now 재통지나 외부 AI 일괄 재분석을 수행하지 않는다.
- 취소/변경 요청을 단톡방 공지 파서가 확정 취소/변경으로 바꾸던 경로도 차단한다. 기존 일정과 연결할 근거가 없으면 별도 변경 정보로 보여주고 이전 일정을 임의로 취소하지 않는다.

## 검증

최종 단위 테스트 274개 통과, 실패/오류 0. APK 및 androidTest 빌드 성공.
추가 회귀: 읽은 시스템 알림만 취소, 읽음 지속/복원, 읽음 표식 만료, 복수 일정 후보, 예약 변경 요청, 취소 요청/완료 구분, 단톡방 확정 공지 유지, 부정/광고/예시 제외, 필터, 한도 소진 상태의 신규 일정 처리, 과거 복구의 멱등성 및 원문 보존.

Galaxy S23 실기기 4개 테스트 통과(76.087초): 읽은 재통지만 취소/미확인 재통지 유지, 이번 복구 항목의 한정 정정, 복구 재실행의 멱등성, 스마트함 조율·변경·취소 화면 표시.
실제 원문을 보존한 채 처음 11개가 추가됐으며, 검토에서 GPU 이용시간/쿠폰 기한 2건을 일정 오분류로 확인했다. 날짜 표현 보완 후 추가된 3건도 모델 버전 숫자의 오인식임을 확인했다. 시간 단위와 시각을 구별하고 상업적 사용 기한 및 소수점 버전 숫자를 제외하는 회귀 테스트를 추가했다. 이번 실행에서 생성된 정확한 ID·생성/수정 시각·상태가 일치하는 파생 이벤트만 정정하며, 수정된 사용자 기록은 건너뛴다. 원문은 삭제하지 않는다.
단말 전체의 알림 개수 전후 차이는 설치/계측 실행 및 새 수신의 영향을 받으므로 읽음의 증거로 사용하지 않는다. 합성 알림의 정확한 태그별 유지/취소와 읽음 저장으로 검증한다.

## 범위와 한계

- 배지는 시스템에 남은 미확인 Now 알림 기준이며, 스마트함과 전체 메시지를 합산한 총 unread 수는 아니다. 홈 런처의 숫자/점 스타일과 갱신 시점은 Samsung One UI 설정에 따른다.
- 날짜나 대상이 없는 “그때요”, “취소해주세요” 등은 이 로컬 추출로 추측하지 않는다. 문맥 판단이 필요하며 기존 분석 한도/실패의 영향을 받을 수 있다.
- 확정 일정과 연결되지 않은 취소 메시지가 과거 일정을 자동 삭제하지 않는다.
- 기기 원문, DB, 로그, APK는 저장소 밖의 비공개 임시 경로에 보관한다.

실제 MainActivity의 Now 상세 읽음 검증도 별도 통과(1.928초): 합성 원문 한 건의 상세를 열면 해당 시스템 알림이 제거되고 읽음이 저장되는 것을 확인했다. 테스트 소스와 채널은 검증 후 제거했다.
