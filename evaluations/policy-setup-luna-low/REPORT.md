# GPT-5.6 Luna low 비교 실험 — 2026-09-23

## 설정과 범위

사용자가 지정한 `gpt-5.6-luna`, `reasoning: {"effort": "low"}`로 실제 OpenAI Responses API를 실행했다. temperature는 제외했다. 기존 프롬프트·지원 기능 목록·strict JSON 스키마·원문 보존 코드·답변 후 추가 대조 검사·2,200 출력 토큰 한도·45초 타임아웃·store:false는 유지했다. 기본 클라이언트 모델은 GPT-4.1 그대로다. 실제 사용자 알림은 보내지 않았다.

기존에 노출된 한국어·영어·혼용 설정40개 및 다회차10개를 재사용했다. 모델만의 순수 통제 실험은 아니다: 추론 설정/temperature와 캐시 적중이 다르며 실행 시점도 다르다. 이번에는 Jev를 재실행하지 않았고 정책 JSON·Android 연결도 하지 않았다.

## 결과

|항목|기존 GPT-4.1|Luna low|
|---|---:|---:|
|설정 상태 일치|40/40 (429 회복 후)|40/40 (서비스 오류 없음)|
|다회차 초기 상태|10/10|10/10|
|다회차 최종 상태|10/10|9/10|
|다회차 어휘 포함 자동 검사|9/10|9/10|

두 모델의 자동9/10은 같은 실패가 아니다. GPT-4.1은 영어 지시를 한국어로 정리해 단어 검사에 실패했다. Luna는 mt-007에서 후보 도착 후에도 waiting을 반환해 선택과 답변 단계에 진입하지 못했다. 따라서 Luna의 흐름 실패를 단순 어휘 검사 실패로 설명하면 안 된다.

검토한 결함:
- mt-007: 후보가 존재하는데도 선택지를 내지 않고 기다림. 실행 불가인 상태로 남겼으며 잘못된 ready/정책 활성화는 없었다.
- mt-009: 초기 충돌 질문에 ‘실제 발신자’와 ‘표시 이름’ 구분을 도입했다. 앱이 보장하지 않는 정체성 개념이다. 최종 지시는 유나 알림 허용 및 Calendar 조건을 유지했지만, 중복 표현과 기존 문장의 비문자적 재작성이 남았다.
- pilot-039: 사람이 해당 기준을 선택하기 전에 특정 사람·채널 이름을 추가로 질문했다. 상태 정답과 질문 UX 품질은 별개다.
- 나머지 완료된 다회차 원문을 검토했으며, 이름·본문 채널 한정·오늘 승인·선택 방 ID·YouTube 채널만 교체하는 조건은 유지됐다. 이는 독립 블라인드 평가나 완전한 의미 동등성 보장이 아니다.

## 비용과 지연

실제 응답67회(설정40, 다회차27), 확인 사용량 예상 **$0.02091594**. 입력92,973토큰 중 캐시72,077, 출력12,746토큰이며 출력 비용에는 추론 토큰이 포함된다. 기존 비교 대상69회 비용은 $0.27503이다. Luna는 한 흐름을 완료하지 못해 호출 수도 적고 캐시도 더 많이 적중했으므로 총액만으로 동등 품질의 절감률을 주장하지 않는다.

설정40개 기준 Luna 비용$0.01096032, 기존 GPT-4.1 $0.161092. 중앙 응답 시간은 Luna 약2.51초, GPT-4.1 약1.80초. Luna 전체 중앙2.60초, p95 4.50초. 대기 간격은 API 지연에서 제외했다. 추론 토큰 및 캐시 미적용 비용 추정은 comparison.json에 별도 기록했다.

최초 제한 환경 호출은 network_or_timeout으로 실패해 `../policy-setup-luna-low-network-attempt`에 보존했다. 네트워크 허용 실행에서 동일 첫 사례부터 새로 시작했다. 이 실패1회는 서버 도달/사용량을 알 수 없으며 위67회 비용에 포함하지 않았다. 실패한 모델 응답을 재시도해서 점수를 올리지 않았다.

## 판단

비용을 낮추는 후보로는 유망하지만 기본 모델을 교체하지 않는다. 후보가 생겼을 때 선택 단계로 이동하는 계약과 불필요한 정체성 구분을 먼저 개선한 뒤, 새 미사용 자료와 반복 실행으로 확인해야 한다. Phase 0 미완료 및 제품 신뢰성 미통과는 유지한다.

검증: 요청 어댑터의 모델/추론/temperature 변경, 원본 요청 불변, 프롬프트·스키마·출력 한도 보존을 오프라인 검사했다. 실제 모든 응답의 model은 gpt-5.6-luna였다. manifest에 자료·실행기·기존 클라이언트 해시를 고정했다.
