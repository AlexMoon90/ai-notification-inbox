# 프롬프트와 시간순 대화 비교 설계

720개의 합성 API 요청을 실행한다. 모델 jev-1.13.0, 병렬 3개, 질문 2개(사건 분류 + 중요 여부), 이진 임계값 0.5 및 높은 점수 관찰용 0.8을 고정했다. API에는 정답과 사례 ID를 전달하지 않는다.

- A_baseline: 기존 질문에서 사건 분류와 중요 여부를 그대로 사용
- B_explicit: 시간순 해석, 생략 복원, 나중 정정 우선, 해결된 과거 사건 재알림 방지, 본인/타인 구분, true/false 기준 명시
- C_examples: B에 별도 예시 4개 추가

A/B/C는 같은 모델·입력·정답으로 비교한다. C는 내용과 길이 모두 달라지므로 예시의 효과와 프롬프트 길이의 효과를 분리하는 실험은 아니다. 기존 평가의 5개 질문과 달리 이번 모든 조건은 동일한 2개 질문만 사용하며, 이전 실행 점수와 직접 비교하지 않고 이번 A를 대조군으로 쓴다.

## 데이터

기존 데이터 120건 × 3개 프롬프트 = 360회. 이미 결과를 본 자료이므로 회귀 검사용이다.

신규 대화 12개 × 5단계 × 문맥 2조건 × 3개 프롬프트 = 360회. 약속 확정/변경/취소, 미납/완납, 답변 요청/완료, 요청 철회, 다른 사람 대상 요청, 교육 예시/실제 보안, 예약, 광고와 실제 사건, 잡담 삽입, 영어, 완료 후 재요청, 잘못된 요청 정정을 포함한다.

`full`은 과거 메시지를 timestamp 순서로 누적한다. `current_only`는 같은 입력에서 과거 메시지만 비운다. 현재 시점 이후의 메시지는 어느 조건에도 없다. 과거 중요 사건의 존재 여부가 아니라 **이번 메시지의 의미와 알릴 필요**를 채점한다. 현재 입력만으로는 풀 수 없는 사례도 같은 전체 맥락 정답으로 채점하므로 current_only의 실패는 모델 오류와 정보 부족을 함께 반영한다.

새 정책은 요청 철회도 알려달라고 명시한다. 기존 데이터셋 정책과 달라도 같은 사례의 A/B/C 정책은 동일하다. GENERAL이라도 정책상 철회를 알릴 수 있다. 다섯 단계는 같은 대화에 속하므로 60개의 독립적인 대화로 계산하면 안 된다. 대화 5단계를 모두 맞힌 개수도 집계한다.

이번 최대 누적 길이는 현재 메시지를 포함해 5개다. 30개 이상 긴 대화나 실제 그룹방의 화자/답장 구조를 검증한 결과가 아니다. 단일 작성자가 새로 만든 합성 사례로, 독립 외부 테스트셋은 아니다.

## 응답 검증 및 재현

이전 결과에서 Choice 확률 합 0.99가 관찰됐다. 이번에는 확률의 소수 둘째 자리 반올림을 고려해 10개 범주의 합에 최대 0.051 오차를 **호출 전에 모든 조건에 동일하게** 허용한다. 원본 확률을 재정규화하지 않는다. 필드·타입·범위·선택값·usage는 별도로 검증한다. 임계값과 라벨을 결과에 맞춰 변경하지 않는다.

```sh
python3 scripts/compare_jev_prompts.py       # 기존 응답 재채점만, 과금 없음
python3 scripts/compare_jev_prompts.py --run # 미실행 요청만 실행
```

질문과 입력 해시는 manifest.json, API 원본은 responses.jsonl, 비교 집계는 summary.json, 사례별 결과는 judgments.jsonl 및 REPORT.md에 보관한다. 실패 요청도 보존하며 자동 재실행하지 않는다. 최종 추천을 하더라도 이번 세트에서 고른 조건을 새 검증셋 없이 운영 품질로 보증하지 않는다.

공식 참고: [State](https://docs.typesafe.ai/concepts/state), [Noul 질문 기준](https://docs.typesafe.ai/primitives/noul), [API](https://docs.typesafe.ai/api).

## 추가 장문 스트레스 실험

별도 `long-context-v1` 폴더에서 요청·답변·일정 변경 6개 사례의 현재 문장을 고정하고, 과거 맥락과 현재 사이에 업무 요청이 없는 잡담을 삽입한다. 전체 메시지 수 10개/30개 × 6사례 × 3프롬프트로 36회를 추가한다. 이 실험에서는 5단계 대화 전체 정답률 대신 현재 마지막 메시지의 분류/중요도만 평가한다. 정답은 원래 시나리오에서 유지하며 미래 메시지를 추가하지 않는다.

`python3 scripts/compare_jev_long_context.py --run`으로 미실행 사례만 실행하고, `--run` 없이 저장된 응답을 재채점한다. 짧은 동일 사례의 결과는 주 실험 timeline/full에서 확인할 수 있다. 장문 세트는 모두 중요한 사례여서 여기서는 과잉 알림률을 측정할 수 없다. 중립 잡담을 늘린 인공 부하이지 다양한 실제 장문 대화를 대표하지 않는다.
